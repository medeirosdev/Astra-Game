superhero-male.glb, superhero-female.glb, anim-library-1.glb, anim-library-2.glb

From Quaternius's "Universal Base Characters" (Standard/free tier), "Universal
Animation Library" and "Universal Animation Library 2" (quaternius.com /
quaternius.itch.io).
License: CC0 1.0 Universal (public domain) — no attribution required, credited here anyway.

Character meshes and both animation libraries share the same 65-bone skeleton, so
animation clips from anim-library-1.glb and anim-library-2.glb are applied directly
(via THREE.AnimationMixer) onto both superhero-male.glb and superhero-female.glb
without any retargeting step — verified by rendering every clip used in the game and
checking the pose didn't break. Library 1 has the base moveset (idle/walk/sprint/
jump/crouch/roll/punch); library 2 supplies the extra per-character combo hits
(Melee_Hook, OverhandThrow, Sword_Regular_A, ver characters.ts).

Original files (Superhero_Male_FullBody.gltf, Superhero_Female_FullBody.gltf) were
converted from separate .gltf+.bin+textures to self-contained .glb via
`gltf-pipeline -b`, and their 2048x2048 textures were downscaled to 512x512 (PIL)
to keep download size reasonable for a browser game — original textures were much
higher resolution than this project's simple lighting setup needs.

Replaces the earlier Kenney "Blocky Characters" models (character-j/l/q.glb) to
get crouch/jump/roll animations, which that pack didn't include.

skin-male-light.png, skin-female-light.png
From the same "Universal Base Characters" Standard pack — the "Light" skin-tone
base color texture (the pack ships one "Dark" and one "Light" variant per gender;
the glb files above already embed "Dark"). Swapped in at runtime per character
(see CharacterModel.loadSkinTexture) only when the character has no outfit set
(see below) — an outfit already brings its own skin texture.

outfits/Male_Ranger.glb, outfits/Male_Peasant.glb, outfits/Female_Ranger.glb
From Quaternius's "Modular Character Outfits - Fantasy" (Standard/free tier —
only Peasant and Ranger are free per gender, the other ~10 outfits are
Source/paid). Same 65-bone rig as the base characters, explicitly built to be
compatible ("compatible with Universal Base Character heads and Universal
Animation Library"). License: CC0 1.0 Universal.

Each outfit file already includes its own full body (arms/legs/feet/torso,
with its own skin texture) — it's a complete alternate body, not just a
garment layer. Attached via bone-name remapping (ver
CharacterModel.attachOutfit/remapSkinIndices): the outfit's skinIndex
attribute is rewritten to point at the SAME cloned skeleton the base
character uses, so it animates for free off the existing AnimationMixer
instead of needing a second one. The base body's own clothing/skin mesh is
hidden (not removed — the skeleton it shares doesn't depend on it) whenever
an outfit is set.

Converted the same way as the base characters (`gltf-pipeline -b`, textures
downscaled 2048→512 via PIL).
